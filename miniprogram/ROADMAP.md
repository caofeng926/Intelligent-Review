## 🚀 V1.1 留存（核心：让用户回来第二次）

工时合计：**5-7 天**

### F1. 我的页面 + 收藏

**目标**：让用户能"保存重要规则"，建立"第二次访问"动机
**关键指标**：收藏 / 浏览量 ≥ 1.5 / 用户，7 日回访 + 15%

**实现**：
- 新增 `pages/me/` tabBar 入口（4 tab → 5 tab）
- 收藏列表（后端持久化：POST /api/fav, GET /api/fav）
- 浏览历史（自动写入 mini_app_user_actions）
- 收藏按钮：详情页 / 列表页右侧星标

**后端新增**：
```sql
CREATE TABLE IF NOT EXISTS mini_app_favs (
  openid TEXT NOT NULL,
  kp_id INTEGER NOT NULL,
  created_at TEXT DEFAULT (datetime('now')),
  PRIMARY KEY (openid, kp_id)
);
```

```python
@app.post("/api/fav")           # 添加/取消
@app.delete("/api/fav")         # 取消
@app.get("/api/fav")            # 列表
```

### F2. 搜索体验升级

**目标**：让搜索更聪明、结果更精准
**关键指标**：搜索 → 点击 转化率 + 20%

**实现**：
- 拼写纠错（后端 levenshtein 距离）
- 同义词扩展（"糖尿病" ↔ "高血糖"）
- 高亮结果（已做）
- "你可能想搜" 联想（基于热搜词）
- 搜索结果按"热度 + 时间" 综合排序

### F3. 扫码查码（增强）

**目标**：让审核员现场扫码反查
**关键指标**：扫码 → 详情页 转化率 ≥ 80%

**实现**：
- 药品包装条形码反查（条形码库关联）
- 一次性识别多码（连续扫码）
- 扫到的结果自动填入搜索框

### F4. 客服消息 + 反馈

**目标**：让用户有问题能找到人
**关键指标**：7 日客服会话量 / 日活 ≥ 5%

**实现**：
- 详情页右下角悬浮客服 button
- "我的" 页"意见反馈"button（open-type="feedback"）
- 公众号绑定（V1.2）

### F5. 订阅消息（政策更新推送）

**目标**：政策更新时主动通知用户
**关键指标**：订阅转化率 ≥ 30%，推送打开率 ≥ 15%

**实现**：
- 详情页底部：「政策更新订阅我」
- wx.requestSubscribeMessage → 用户授权
- 后端定时任务：每周/每天扫描 `pub_date` 新增的 KP
- 对订阅用户下发：「医保局新发布了 N 条规则」

## 🌱 V1.2 增长（核心：让更多人知道）

工时合计：**7-10 天**

### G1. 微信搜索 SEO

**目标**：用户在微信搜「医保审核规则」「医保编码」能找到我们
**关键指标**：微信搜索 UV / 总 UV ≥ 30%

**实现**：
- 小程序后台 → 推广 → **自定义关键词**：医保审核、医保规则、医保编码、医用耗材、ICD、医保药品
- sitemap.json：确保所有页面 allow（已做）
- 页面 title 优化（搜索结果展示）
- 名称/简介/标签含核心关键词

### G2. 分享回流（裂变）

**目标**：让分享成为新用户来源
**关键指标**：分享回流率 ≥ 15%，分享 UV / 总 UV ≥ 25%

**实现**：
- 详情页分享图片（自动生成：规则名 + 二维码）
- 分享卡片：「医保审核员必备工具」
- 分享回流：被分享者打开后看到「来自好友分享」banner
- 邀请奖励：分享 N 次解锁某个功能（合规审核通过的前提下）

### G3. 公众号 + 视频号联动

**目标**：私域引流
**关键指标**：公众号文章带小程序点击率

**实现**：
- 公众号关联小程序（菜单 → 小程序卡片）
- 公众号文章末尾插入「立即查询」小程序链接
- 视频号绑定（主页 → 小程序入口）
- 短视频内容：「医保审核员的一天」「这 3 个规则你必须知道」

### G4. 海报生成（朋友圈种草）

**目标**：让用户主动分享到朋友圈
**关键指标**：海报分享数 ≥ 100/日

**实现**：
- 详情页 / 我的页：生成「我的医保智审成绩单」海报
- 海报含小程序码（scene 参数记录来源）
- 扫码进入自动 attribution

## 💰 V1.3 增长 + 变现

工时合计：**10-14 天**

### M1. 广告位开通

**前置条件**：累计独立访客（UV）≥ 1000
**关键指标**：CPM 单价 + 点击率

**实现**：
- 申请流量主（小程序后台 → 流量主）
- 首页底部 banner 广告
- 搜索结果穿插广告位
- 视频广告（看完送一次免费高级搜索）

### M2. AI 问答（联合后端 QA 引擎）

**目标**：让用户用自然语言查询
**关键指标**：AI 问答 → 详情页 转化率

**实现**：
- 首页底部"AI 智能问答"入口
- 输入：「糖尿病有什么审核规则」
- 后端 LLM 解析 → 调用 `/api/search` + 后处理
- 限流：每个用户每天 10 次免费，超出后引导分享解锁

### M3. 高级会员（订阅式）

**目标**：核心用户付费
**关键指标**：付费转化率 ≥ 3%

**实现**：
- V1.1 阶段用「免费 + 高级」分层
- 高级功能：批量导出 / 离线缓存 / 历史比对
- 微信支付 V3 API

### M4. 数据导出

**目标**：审核员可批量导出规则
**关键指标**：导出 → 桌面分享 ≥ 5%

**实现**：
- 搜索结果页"批量导出"按钮
- 生成 CSV / Excel 文件
- 通过 wx.openDocument 打开 + 转发

## 📊 增长公式（KPI 拆解）

```
DAU = 搜索 UV + 分享回流 UV + 微信搜索 UV + 直接访问 UV + 推送回流 UV

V1.0 目标: DAU = 100-500
   ├─ 直接访问 (二维码扫码): 50-200
   ├─ 微信搜索 (SEO + sitemap): 30-150
   └─ 分享回流: 20-150

V1.1 目标: DAU = 500-1500
   + 推送回流 (订阅消息): 100-500
   + 7 日回访提升: 30%

V1.2 目标: DAU = 1500-5000
   + 海报分享 + 公众号: 800-2500
   + 微信搜索 (关键词覆盖): 200-1000
```
